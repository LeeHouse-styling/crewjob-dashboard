크루잡 - 항공사 채용정보

크루잡 계정은 앱 안에서 직접 삭제하실 수 있습니다. 별도 신청이나 대기 없이 즉시 처리됩니다.

앱에서 삭제하기

  1. 크루잡 앱을 실행하고 로그인합니다.
  2. 홈 화면 오른쪽 위의 설정 아이콘을 누릅니다.
  3. 화면을 아래로 내려 회원 탈퇴를 누릅니다.
  4. 안내를 확인하고 계속 → 탈퇴하기를 누릅니다.
탈퇴는 되돌릴 수 없습니다. 확인 절차를 두 번 거치도록 되어 있으니 신중히 진행해 주세요.
